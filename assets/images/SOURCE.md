# Where the pictures come from

Copied from the Windows 95 shell's icon set (wippy-windows/windows,
`assets/icons/SOURCE.md`): `taskmgr` at 32 and 16 px, Microsoft's artwork
from `shell32.dll` (the Windows 98 `w98_computer_taskmgr.ico` of the same
set), extracted there from the original `.ico` file as RGBA PNG. This is not
part of the module under MIT; the file name is the picture's name in the
pack, `windows.taskman:images/taskmgr`. The pictures of the windows on the
Applications tab are not here — they arrive with the compositor's list.
